# 기능 명세서 — 찾았다, 한양대 자취

> **기준** 실제 코드(frontend, backend, ai-server)에 구현된 기능만 적었다.
> **API 경로** 모두 `/api/v1` 뒤에 붙는다. 요청과 응답은 API 명세서에 있다.
> **우선순위** P0 서비스 핵심, P1 주요 기능, P2 편의와 고도화
