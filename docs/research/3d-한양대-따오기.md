# 한양대 서울캠퍼스 3D로 따오기 — 방법 조사

> 대상: **한양대학교 서울캠퍼스 (서울 성동구 행당동·사근동)**
> 범위: 건물 디테일은 나중. 먼저 **땅(지형)·길·캠퍼스 경계·입구·바닥 텍스처**를 실제 데이터로 가져올 수 있는지 확인
> 작성: 2026-11-07

---

## 0. 결론 먼저

**가능하다.** 무료 공개 데이터만으로 한양대 서울캠퍼스의 **경계·길·계단·건물 윤곽·지형 높낮이**를 가져올 수 있다는 걸 실제 조회로 확인했다.
추천 경로: **OSM(길·경계·건물 윤곽) + DEM(지형) → Blender 또는 코드로 변환 → glTF → three.js**.
실사 수준(사진 같은 3D)은 공개 데이터로는 어렵고, 원하면 **직접 촬영(Gaussian Splatting)** 으로 일부 구역만 만든다.

## 3. 추천 파이프라인 (해커톤용)

**1단계 — 땅과 길 (먼저 이것부터 검증)**
1. Overpass로 캠퍼스 경계 + 주변 1km의 길·계단·녹지·건물 윤곽 받기 (JSON/GeoJSON)
2. AWS Terrarium 지형 타일로 높이 메시 생성
3. 길·녹지를 지형 위에 투영 (색칠한 스타일라이즈 바닥)
4. three.js에서 캐릭터가 지형 위를 걷는지 확인 → **"한양대를 따올 수 있다" 검증 완료**

**2단계 — 정확도 올리기**
5. 국토지리정보원 DEM으로 지형 교체 (언덕 정확도)
6. 정문·후문·애지문 등 **캠퍼스 입구를 직접 좌표로 표시** (OSM에 이름 없음)
7. 현장 확인으로 누락된 길·계단 보정

**3단계 — 건물 (나중)**
8. OSM 윤곽 압출 + 층수 직접 입력 (높이 태그가 거의 없음)
9. 랜드마크 1~2개만 직접 촬영 splat 또는 수작업 모델

## 4-1. 「산사처럼 예쁘게」 — 데이터가 아니라 아트가 결정한다

### 산사가 예쁜 이유 (2026-11-07, 산사 번들·리소스 직접 분석)
| 요소 | 확인된 것 | 의미 |
|---|---|---|
| **재질** | 재질 폴더가 **딱 5종**: wood, stone, plaster, roof, cloth. 각각 color + normal + roughness 3장 | 반복 타일 **PBR 텍스처 몇 장**으로 전부 칠한다. 많을 필요 없다 |
| **3D 모델 파일** | GLB는 불상·보살상·스님 캐릭터·고양이뿐 | **법당 같은 건물은 코드로 만든 형태에 재질만 입힌 것**으로 보인다 → 한양대 건물도 OSM 윤곽 + 재질로 같은 방식 가능 |
| **배경** | `environment/woodland.jpg` 파노라마 1장 | 멀리 보이는 숲·하늘을 사진 한 장으로 처리 |
| **빛·톤** | ACES/AgX/Neutral 톤매핑, HemisphereLight + DirectionalLight, **FogExp2(안개)**, CSM(그림자 분할) | 따뜻한 색감·깊이감의 핵심 |
| **식생** | 번들에 `grass`, `leaf`, `wind`, `onBeforeCompile`, `InstancedMesh` | 나무·풀을 **인스턴싱**으로 대량 배치 + **셰이더로 바람에 흔들리게** |
| **디테일** | lightMap, aoMap, normalMap | 구워 둔 그림자·틈새 어둠으로 입체감 |
| **최적화** | `LOD`, `monk-remote-lod.glb`(다른 접속자용 저해상도 캐릭터), BVH 충돌 | 예쁘면서도 가볍게 |
| **연출** | 등불, 연꽃, 단풍, 벤치, 연못(Water), 카페 | **소품과 계절감**이 분위기의 절반 |

→ 결론: 산사 느낌은 **"실제 데이터 + 적은 수의 좋은 재질 + 안개·톤매핑 + 흔들리는 나무 + 계절 소품"** 조합이다. 실사 3D 데이터가 없어도 된다.

### 한양대에 적용하는 레시피
1. **바닥·길:** OSM 길 → 보도블록·잔디·흙 재질 3~4종, 계단은 OSM `steps`에서 생성
2. **건물:** OSM 윤곽 압출 + 재질 4~5종(벽돌·콘크리트·유리·지붕). **실제 외벽 재질은 현장 사진으로 확인**해서 고른다
3. **랜드마크:** 애지문(104), 본관(102), 역사관(101), 노천극장(209) 등 2~3개만 정성 들여 모델링 (번호는 2017 건물 목록 기준)
4. **식생:** **EZ-Tree**로 나무 몇 종 생성(바람 애니메이션 내장, GLB 내보내기 가능) → 인스턴싱으로 배치. OSM `forest` 21개 구역에 자동으로 심기
5. **분위기:** 계절 하나를 정한다 (산사처럼 **가을 단풍** 또는 **봄 벚꽃**) → 안개 + 톤매핑 + 파노라마 배경
6. **소품:** 벤치, 가로등, 자전거 거치대, 사자(한양 라이언스) 조형 등 → CC0 에셋 + AI 3D 생성
7. **캐릭터:** 과잠 입은 귀여운 학생 1종 + Mixamo 걷기·뛰기 애니메이션
