## 1. 이미 쓰는 것 — 공공데이터포털 '국토교통부_건축HUB_건축물대장정보 서비스' (키 1개로 전부)
| 기능 | 쓰임 | 상태 |
|---|---|---|
| 표제부 `getBrTitleInfo` | 건물별 층수·높이·구조·지붕·연면적·사용승인일 → 3D 높이 | ✅ 50개 건물 연결, 3D 35동 반영 |
| 층별개요 `getBrFlrOulnInfo` | 층마다 용도·면적 (강의실/연구실/로비 등) → 입구 층, 실내 안내 | ✅ 578개 층 기록 |
| 기본개요 `getBrBasisOulnInfo` | **건물ID(bldgId)** → 지도 도형과 위치로 연결하는 열쇠 | ✅ 59개 건물ID 확보 |
| 총괄표제부 `getBrRecapTitleInfo` | 캠퍼스 전체: 대지 520,262㎡, 건폐율 21.6%, 용적률 116%, 주건축물 85동 | ✅ `campus/_ledger/campus_recap.json` |

| 전유부·주택가격 | 대학 건물엔 데이터 없음 (원룸 매물엔 씀 → 아래 3번) | — |

## 2. 신청 추천 — 3D 정확도
| API | 왜 필요 | 신청 |
|---|---|---|
| ⚠️ **국토교통부_GIS건물통합정보** (브이월드 `LT_C_BLDGINFO`) | 키 발급·호출 성공 (캠퍼스 주변 1,387동). **하지만 한 필지에 85동이 몰린 한양대는 속성이 다른 도형에 붙어 있음** — 검증 38개 중 28개가 수백 m 어긋남 → 위치 연결용으로 못 씀. 도형만 참고 (`campus/_ledger/vworld_bldginfo.geojson`) | 브이월드 키 `.env` 의 `VWORLD_KEY` |
| ⚪ 국토교통부_GIS건물일반집합정보 | 위와 비슷한 융합 정보 | [data.go.kr/data/15123552](https://www.data.go.kr/data/15123552/openapi.do) — 위 하나면 충분 |
| ✅ 국토지리정보원 수치지도 1:5000 (파일) | 등고선·표고점 → 2m 지형, 옹벽·계단·건물 층수 | 국토정보맵에서 받음 (37705072·073). 공개DEM은 90m라 안 씀 |

## 3. 신청 필요 — 서비스 기능
| API | 기능 (명세서 ID) | 신청 |
|---|---|---|
| 🟡 **국토교통부 전월세 실거래가** (연립다세대·오피스텔·단독다가구) | **바가지 혐의** 판정 기준선 (D3) | 공공데이터포털 활용신청 (같은 계정) |
| ✅ 건축물대장 (위와 같은 키) | 매물 건물의 용도·위반건축물 → **신분 위장 혐의** (D6, L1) | 이미 있음 |
| 🟡 **카카오 개발자 JavaScript 키** | 2D 지도(C1) + **실제 로드뷰로 보기**(매물 상세) | developers.kakao.com 앱 등록, 사이트 도메인에 localhost 추가 |
| 🟡 **TMAP 보행자 경로** (SK open API) | 집 → 입구 → 과 건물 **등굣길** (F1) | openapi.sk.com 앱 등록 |
| ⚪ 청년안심주택·LH 공고 | 공고 캘린더 (I6) | 공식 API 확인 필요 — 우선 공고문 수동 등록 |
| ⚪ Claude API | 공고 요약·후기 요약 (I9, G3) | 서버(Java)에서 호출 |

## 순서 제안
1. **GIS건물통합정보** 신청 → 3D 캠퍼스 정확도 마무리

3. **전월세 실거래가** → 바가지 판정
4. **TMAP** → 등굣길
